# 볼 꼬집기

사진을 불러와 볼을 누른 채 당기면 피부처럼 늘어나고, 놓으면 출렁이며 원래대로 돌아오는 웹 시제품.
사진은 기기 밖으로 나가지 않는다.

## 실행 주소
- 라이브(GitHub Pages, `main`에 올리면 1~2분 뒤 자동 반영): https://jinavav15000-star.github.io/cheek-play/
- 저장소: https://github.com/jinavav15000-star/cheek-play (공개)

## 맥에서 직접 띄우기
```bash
./serve.sh
```
출력된 `http://<맥 IP>:8417` 주소를 같은 와이파이의 폰 브라우저(크롬/삼성 인터넷)에서 연다.
맥 방화벽이 python 수신 연결을 물으면 허용한다.

## 쓰는 법
1. 처음 열면 시범 손가락이 사용법을 보여준다 (상단 `?`로 다시 보기)
2. **사진 불러오기** → 갤러리·카메라·샘플. 볼을 자동으로 찾는다(처음 한 번 인식 파일 약 7MB). 얼굴이 작으면 두 손가락으로 벌려 확대, 빈 곳을 끌어 이동
3. 자동 인식이 틀리면 **볼 위치 맞추기** → 사진을 톡 눌러 원을 옮기거나 화살표·크기·추가·삭제·다시 찾기 → 완료
4. 볼을 누른 채 끌었다 놓기 (두 손가락으로 양볼 동시에 가능). 세게 당긴 뒤엔 [이 장면 저장·공유] 칩
5. **느낌 조절** → 말랑/쫀득/탱탱 프리셋, 더 세밀하게
4. **느낌 조절** → 출렁이는 속도/정도, 늘어나는 한계, 잡히는 범위를 만지면서 바로 시험

## 의견 보내기 링크
`app.js` 맨 위 `FEEDBACK_URL`에 구글 폼 주소를 넣는다(비어 있으면 버튼이 숨겨진다). `FEEDBACK_PREFILL`로 당긴 횟수·얼굴 수·기기 종류·프리셋 이름을 미리 채울 수 있다.
