# 볼 꼬집기

사진을 불러와 볼을 누른 채 당기면 피부처럼 늘어나고, 놓으면 출렁이며 원래대로 돌아오는 웹 시제품.
사진은 기기 밖으로 나가지 않는다.

## 실행 주소
- 라이브(GitHub Pages, `main`에 올리면 1~2분 뒤 자동 반영): https://jinavav15000-star.github.io/cheek-play/
- 저장소: https://github.com/jinavav15000-star/cheek-play (공개)

## 맥에서 직접 띄우기
```bash
./serve.sh
```
출력된 `http://<맥 IP>:8417` 주소를 같은 와이파이의 폰 브라우저(크롬/삼성 인터넷)에서 연다.
맥 방화벽이 python 수신 연결을 물으면 허용한다.

## 쓰는 법
1. 처음 열면 시범 손가락이 사용법을 보여준다 (상단 `?`로 다시 보기)
2. **사진 불러오기** → 갤러리에서 선택하면 볼을 자동으로 찾는다. 얼굴이 작으면 얼굴 쪽으로 확대된다
3. 자동 인식이 틀리면 **볼 위치** → 원을 볼 위로 옮기고 모서리 점으로 크기 조절 → 완료
4. 볼을 누른 채 당겼다 놓기 (두 손가락으로 양볼 동시에 가능)
4. **느낌 조절** → 출렁이는 속도/정도, 늘어나는 한계, 잡히는 범위를 만지면서 바로 시험

## 의견 보내기 링크
`app.js` 맨 위 `FEEDBACK_URL`에 구글 폼 주소를 넣는다.

구조와 주의점은 `CLAUDE.md` 참고.
