# 샘플 사진

`baby1.jpg`, `baby2.jpg`, `baby3.jpg` — 2026-09-23에 OpenAI Codex의 내장 이미지 생성 도구로 만든 **가상의 아기**다. 실존 인물이 아니며, 실존 인물을 닮도록 만들지 않았다.

- 요청 요지: 사진처럼 사실적인 생후 6~12개월 아기, 통통한 볼이 보이는 정면 클로즈업, 단순한 파스텔 배경, 900×1200, 각각 다른 아기 (니트 모자·크림 배경 / 머리숱 많음·하늘색 배경 / 노란 옷·연분홍 배경).
- 사용 목적: 사진을 넣기 전에 앱을 바로 만져볼 수 있는 연습용. 볼 좌표는 `app.js`의 `SAMPLES`에 미리 계산해 두었다.
- 사진을 바꾸면 `app.js`의 좌표를 다시 계산하고(`__cheek.detectFaces`), 이 문서와 출처를 갱신한다.
